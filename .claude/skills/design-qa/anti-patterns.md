# Design QA Anti Patterns

Claude must flag these quickly:

## Conversion issues

- vague hero
- weak or buried CTA
- too many CTAs
- no trust layer
- no objection handling where needed

## Design issues

- generic SaaS look
- repeated card sections
- flat hierarchy
- visual clutter
- random decorative elements
- too much visual weight in the wrong places

## Layout issues

- cramped spacing
- excessive whitespace with no purpose
- poor alignment
- stretched text width
- fragile grids

## Mobile issues

- desktop first squeeze down
- unreadable text
- tiny tap targets
- broken stacking
- awkward nav
- overflow

## Typography issues

- giant hero text that wraps badly
- weak contrast between heading and body
- dense paragraphs
- too many font sizes
- inconsistent text rhythm

## Accessibility issues

- missing labels
- poor focus states
- bad contrast
- clickable non semantic elements
- hover dependent interactions

## SEO issues

- vague H1
- decorative headings
- page topic not obvious early
- weak semantic structure
- fake FAQ sections

## Motion issues

- long delays
- too many scroll effects
- motion competing with CTA
- animation hiding content
- motion without reduced mode respect

## Code issues

- chaotic Tailwind
- unnecessary wrappers
- bloated JS
- fragile implementation
