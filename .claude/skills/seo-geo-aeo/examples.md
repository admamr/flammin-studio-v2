## Example 3, Article Opening

Topic:
What is AEO in web design

Opening answer block:
AEO, or Answer Engine Optimization, is the practice of structuring website content so search engines and AI systems can identify, extract, and present direct answers more easily. In web design, this means using clear headings, direct explanations, FAQ sections, and content that matches real user questions.

Reasoning:

- answer appears early
- direct definition
- easy to extract
- strong informational intent match

---
