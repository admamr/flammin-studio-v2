# SEO GEO AEO Anti Patterns

Claude must avoid the following:

## Keyword stuffing

- repeating the same keyword unnaturally
- forcing exact match phrases into every heading
- bloating copy to include multiple keyword variations

## Metadata mistakes

- vague title tags
- generic meta descriptions
- titles that target too many topics
- title and description mismatch with page content

## Structure mistakes

- multiple topics fighting on one page
- weak heading hierarchy
- decorative headings with no information value
- repeating the same point in multiple sections

## Content mistakes

- long filler intros
- generic marketing language
- article style content on service pages with no decision value
- overexplaining simple ideas with fluff
- writing for algorithms instead of humans

## FAQ mistakes

- fake questions
- thin answers
- keyword stuffed question phrasing
- FAQ added only for schema with no user value

## Internal link mistakes

- too many links
- vague anchor text
- unrelated links inserted for SEO
- linking without supporting user journey

## GEO and AEO mistakes

- writing vague content that cannot be extracted cleanly
- failing to define terms directly
- hiding the main answer deep in the page
- unclear entity relationships

## Schema mistakes

- schema that does not match visible content
- FAQ schema for low quality FAQs
- misleading service or business markup
- adding every possible schema type with no reason

## Local SEO mistakes

- city stuffing
- duplicate location pages with no differentiation
- pretending local relevance where none exists
- copying the same content across many geo pages

## Trust mistakes

- exaggerated claims
- fake authority language
- unclear business identity
- content that sounds polished but not useful
