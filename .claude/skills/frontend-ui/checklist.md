# Frontend UI Checklist

Use this checklist before finalizing any page or section.

## Structure

- Is the HTML semantic
- Is the heading hierarchy correct
- Is the layout easy to understand
- Is the markup cleaner than the fastest lazy version

## Layout

- Is the section width controlled properly
- Is spacing consistent
- Is there a clear visual hierarchy
- Does the layout feel balanced

## Responsiveness

- Does the page work on mobile first
- Do columns stack cleanly
- Is there any horizontal overflow
- Are text sizes appropriate on mobile
- Are buttons easy to tap
- Is navigation usable on smaller screens

## Tailwind Usage

- Are classes readable and intentional
- Are arbitrary values limited
- Is spacing consistent with a clear scale
- Are responsive modifiers used cleanly
- Are styles maintainable for future edits

## Typography

- Does the heading stand out properly
- Is body text readable
- Are paragraphs short enough
- Is line height comfortable
- Is text width controlled for readability

## Buttons and CTAs

- Is the primary button visually dominant
- Are button styles consistent
- Are hover and focus states clear
- Do buttons remain readable and tappable on mobile

## Forms

- Do inputs have labels
- Is field spacing consistent
- Are forms readable on mobile
- Is the submit action clear
- Are field sizes comfortable for users

## JavaScript

- Is JS used only where needed
- Are functions clean and readable
- Are interactions simple and maintainable
- Does the logic avoid unnecessary complexity

## Accessibility

- Are interactive elements keyboard friendly
- Are labels and aria attributes used where needed
- Are focus states visible
- Is contrast acceptable
- Is the UI usable without relying only on hover

## Final QA

- Does the page feel production ready
- Is the code clean enough to hand off later
- Does the UI support conversion and not fight it
- Would future edits be easy
