# Frontend UI Examples

## Example 1, Responsive section shell

### Goal

Create a clean section wrapper with strong spacing and readable width.

```html
<section class="px-4 py-16 sm:px-6 lg:px-8 lg:py-24">
  <div class="mx-auto max-w-7xl">
    <div class="mx-auto max-w-3xl text-center">
      <h2 class="text-3xl font-bold tracking-tight sm:text-4xl">
        Section heading
      </h2>
      <p class="mt-4 text-base leading-7 text-neutral-600 sm:text-lg">
        Supportive section copy that stays readable and does not stretch too
        wide.
      </p>
    </div>
  </div>
</section>
```
