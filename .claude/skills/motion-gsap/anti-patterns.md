# Motion Anti Patterns

Claude must avoid:

## Performance mistakes

- animating width
- animating height for large layout blocks
- animating margin or padding without strong reason
- too many simultaneous scroll triggers
- heavy continuous motion

## CRO mistakes

- delaying headline visibility
- delaying CTA appearance too long
- hiding proof or trust content behind slow animation
- making users wait before they understand the page

## Visual mistakes

- bounce easing
- elastic easing
- exaggerated movement distances
- large rotations with no purpose
- dramatic cinematic motion on simple business pages

## Scroll mistakes

- animating every section
- scroll hijacking
- pinned gimmicks
- late trigger points that reveal content after the user is already reading it

## Mobile mistakes

- desktop level animation intensity on mobile
- long durations on smaller screens
- heavy motion that causes lag
- large transforms that feel unstable

## Accessibility mistakes

- no reduced motion support
- motion only communication
- overwhelming movement
- flashing or aggressive transitions

## Strategic mistakes

- adding motion because the page feels “too static”
- using animation to hide weak design
- copying trendy animations from reference sites without adapting them
- making the website feel like a demo reel instead of a conversion page
