# Motion Principles

Motion must feel:

- intentional
- premium
- controlled
- modern
- responsive

Motion must do one of the following:

- reveal hierarchy
- support reading flow
- clarify interaction
- add subtle polish

Motion must not:

- delay understanding
- distract from the offer
- create friction
- overwhelm the page

Default motion attitude:

- subtle first
- stronger only when justified
- remove anything decorative
- preserve clarity at all times
